Optional local setup
====================

Binder users do not need these steps. Use the links in README.md instead.

Windows (PowerShell)
--------------------
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt jupyterlab ipykernel
.\.venv\Scripts\python.exe -m jupyter lab

macOS / Linux
-------------
python3.12 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt jupyterlab ipykernel
./.venv/bin/python -m jupyter lab

Activation is not required. In VS Code, select .venv as the notebook kernel.
